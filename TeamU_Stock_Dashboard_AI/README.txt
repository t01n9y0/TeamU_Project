TeamU Stock AI Insights v1

這版已加入：
1. 搜尋當日持股相關新聞
2. 新聞摘要與利多 / 利空判讀
3. AI 個股建議
4. 整體持股風險與機會分析

使用方式：
1. index.html、style.css、script.js 全部覆蓋網站原檔。
2. AppsScript_Code.gs 覆蓋 Apps Script。
3. Apps Script 儲存後：
   部署 → 管理部署作業 → 編輯 → 建立新版本 → 部署。
4. 若要啟用 AI：
   Apps Script 左側「專案設定」→「指令碼屬性」新增：
   - GEMINI_API_KEY = 你的 Gemini API Key
   - OPENAI_MODEL = 你的可用文字模型名稱
     若先不填 OPENAI_MODEL，程式預設使用 gpt-4.1-mini。
5. 若暫時不填 GEMINI_API_KEY，網站仍會抓取今日新聞，但 AI 分析區會顯示尚未設定。

備註：
- 新聞先使用 Google News RSS 搜尋，並在 Apps Script 端篩選「台灣日期的今日新聞」。
- AI 分析依照持股資料與新聞標題進行資訊整理，不構成投資建議。


v2新增：
1. 持股損益改為預估賣出後損益：
   帳面市值 - 投資成本 - 預估賣出手續費 - 預估證券交易稅
2. 加入亮暗模式切換，會記住使用者選擇。
3. 手機版持股監控矩陣改為卡片式瀏覽，方便直向閱讀。

   這樣「帳面市值 - 投資成本 = 損益」，卡片與表格口徑一致。

   表格、標題、股名、一般數值、新聞區塊與提示文字在亮色模式下皆可正常閱讀。

   - AppsScript_Code.gs
   - style.css
   其他檔案可維持原樣；壓縮包仍附完整網站檔案，方便整包覆蓋。
